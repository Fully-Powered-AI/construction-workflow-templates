# Lender draw package index: trial on its example, run again after editing

- **Product:** Claude, run in Claude Code
- **Model:** Claude Sonnet 5.5 (model ID claude-sonnet-5-5), for the latest run recorded below, made by the editing session
- **Date:** 2026-11-10

The template was tried on its invented example on 10 November 2026; that first run raised eight judgement calls (listed below). The instructions, the output format and the example were then edited to settle them, and the template was run again on the same example by the editing session. After an independent review, minor wording points were applied (the settings govern project and period; a payee mismatch is reported once; the word optional in the format; the lender and both as-of dates moved into the example's settings line), and the edited instruction block and format were applied to the example once more by the same session. The latest run applies the edited block and format to the same invented example ("Project Delta", draw 5, October 2026): the settings, the lender's checklist, the draw schedule, the accounting export and the list of attachments. No client data was used. The latest run was made by the session that made the edits, so it is not an independent reading; an independent run of the edited version has not been made.

## What was observed

- Every part of the format was produced, and nothing in the run called for a stop.
- Every count, amount and difference matched the example's output, line for line, including the status wording and the Totals line.
- F-0770 stayed in the ledger totals and S-2231 stayed out of the budget-line reconciliation, as the edited instructions now state.
- The basis line took the lender, the checklist date and both "as of" dates from the settings, where the example now states them, as the instructions name them.
- Item 6 printed as "(the draw), optional. Not supplied.", which the format now provides for.
- The "Not checked" line followed the stated minimum (attachment contents, lien status and title) and added two further items with the reason.
- The run did not exercise the cases the edits cover but the example does not contain: a Draw item with a file name and no date, a blank file name, and a missing form total. Those are covered by the acceptance tests, which have not been run.

## The earlier run's judgement calls and what was done

1. The instruction block did not contain the output format: the section now says to paste the block together with the format.
2. Whether ledger entries not in the draw count in the Totals line: the format and the block now say they do.
3. Whether an invoice with a status that is not posted stays in the ledger totals: the procedure and the block now say it does.
4. Whether ledger-only entries are left out of the reconciliation: now stated. Treatment of an invoice found under another payee in the split of the total difference: now stated as not found.
5. The "Not checked" line had no stated minimum: now stated, and "Checks that agree" is defined.
6. Lender, checklist version or date, and the two "as of" dates were not settings: now they are.
7. The form-total wording differed between procedure and format: now one wording, "Form total not supplied."
8. A Draw item with a file name and no document date had no status wording: now "Missing, listed without a document date".

The earlier run's other observations stand: its output matched the example's counts and amounts, and the example's extra line "The documents were not read." was not called for by the format; it has been removed from the example.
